# Characters

The live profile, character and Ascension fields are authoritative. The
[Ironclad wiki page](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Ironclad)
records these reference facts:

- Ironclad starts with 80 Max HP at Ascension 0 and above; the page states that
  Ascension 2 and above starts at 64 HP.
- The starting relic is Burning Blood, which heals 6 HP at the end of combat.
- The starting deck is Strike ×5, Defend ×4 and Bash ×1.
- The regular Ironclad card pool is divided into 20 Common, 35 Uncommon and 25
  Rare cards. The page also lists the character-exclusive relics and potions.

These facts describe the reference loadout only. A transformed, upgraded or
modified live card and every current run's state must be read from the sensor.
This note contains no tier list or route prescription.
