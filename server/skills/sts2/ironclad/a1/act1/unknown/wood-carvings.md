# Wood Carvings

**Biome:** Overgrowth only. **Condition:** at least 1 basic card.

## Options

| Option | Exact outcome |
|---|---|
| **[Bird]** | Choose 1 starter card to Transform into **Peck**. Peck is a 1-energy Event Attack that deals 2 damage 3 times (4 times when upgraded). |
| **[Snake]** | Enchant 1 card with **Slither**. Slither randomizes that card's cost from 0 to 3 when drawn. The option is locked if no card can receive Slither. |
| **[Torus]** | Choose 1 starter card to Transform into **Toric Toughness**. Toric Toughness costs 2 Energy, gains 5 Block (7 when upgraded), and gains 5 Block (7 when upgraded) at the start of the next 2 turns. |

## Notes [wiki-driven]

As with other Transform effects, any prior Enchantment is lost when the card is
transformed. The parenthesized values above are upgraded-card values; the wiki
lists no separate event ascension variant.

Compare the exact transform or enchantment with current deck state and follow
the live option text if it differs.
