# Relics

The [STS2 Relics page](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Relics)
defines Relics as permanent items that give a passive bonus for the duration of
the run. The [Relics List](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Relics_List)
is the catalog of names, rarity, character and source. The live Relic
description and counter outrank either page.

## Ironclad identity

The [Ironclad page](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Ironclad)
lists these Ironclad-exclusive Relics:

| Rarity | Relics |

| Rare | [Charon's Ashes](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Charon%27s_Ashes), [Demon Tongue](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Demon_Tongue), [Ruined Helmet](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Ruined_Helmet) |
| Shop | [Brimstone](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Brimstone) |

The same page records Burning Blood as Ironclad's starting Relic and says it
heals 6 HP at the end of combat. It also identifies the character-exclusive
Potion pool; see [POTIONS.md](../potion/POTIONS.md).

## Reading a Relic

Follow an individual page from the [Relics List](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Relics_List)
when a trigger, amount, counter, source or rarity matters, then compare it with
the live description and counter. A relic may interact with card keywords,
buffs, debuffs, piles, map locations or shop rules; use the linked [Keywords](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Keywords),
[Buffs](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Buffs) and
[Debuffs](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Debuffs) pages for
definitions.

## Comparison worksheet

Compare a Relic's observed trigger and payoff with the current deck, HP, gold,
potions, map and upcoming encounters. Calculate the opportunity cost and the
risk of a trigger failing; do not use a fixed ranking or a “best relic” rule.
An interaction not established by the source or live state remains a hypothesis.

Ancient, Shop and Event Relics can have source-specific restrictions. Read the
current room and exact page rather than assuming that a relic's category implies
its availability or effect.
