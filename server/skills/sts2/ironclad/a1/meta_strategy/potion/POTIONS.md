# Potions

Potions are single-use consumables that persist across floors. The [STS2 Potions page](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Potions)
defines Potion slots, acquisition and outside-combat use; the [Potions List](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Potions_List)
is the current name, rarity, character and effect catalog. The live Potion text,
slot and `target_type` are authoritative.

## Availability and use

The [Potions page](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Potions)
states that the only Potions usable outside combat are Ambergris, Entropic Brew,
Foul Potion when used against the Merchant, Fruit Juice and Blood Potion for
Ironclad. The Merchant always offers 3 Potions in its standard shop; see [The Merchant](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:The_Merchant).

Use the current Potion slot and `target_type` with the runtime's `use_potion`
action. Potions do not become card plays merely because their effect creates or
plays a card; read the live effect and restrictions. Compare using a one-use
resource now with carrying it through the remaining route, and re-read after a
random or selection result. This is a calculation for the current run, not a
Potion priority list.
