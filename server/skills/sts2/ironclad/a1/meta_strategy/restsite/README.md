# Rest Sites — Decision Framework

## Default Options (Sourced)

Source: slaythespire.wiki.gg (Slay the Spire 2:Map_Locations, revision 50028)

| Option | Effect |
|---|---|
| **Rest** | Heal 30% of max HP (rounded down) |
| **Smith** | Upgrade a card in your deck |

## Relic-Granted Options (Sourced)

Source: slaythespire2.net relic database (beta v0.111.0)

| Relic | Added Option | Effect |
|---|---|---|
| **Girya** (Rare) | Strength gain | +1 Strength per visit (max 3 total across run) |
| **Shovel** (Rare) | Dig | Obtain a random Relic |
| **Miniature Tent** (Shop) | Any number of options | Choose multiple Rest Site actions |
| **Meat Cleaver** (Ancient) | Cook | Effect per relic text — verify in installed build |

## Survival Defaults (From controls/CONTROLS.md)

The existing execution contract provides survival guidelines:
- "Below 40% HP prefer a rest site to a fight, and rest rather than smith."
- "Never enter an elite below 60% HP."

{strategic inference} These are experience-based thresholds from the controls documentation, not game-mechanical rules. Ironclad's Burning Blood (6 HP heal per combat) changes the calculus — the decision framework should be adapted as you observe real game outcomes.

## Smith Priority (Strategic Inference)

{strategic inference} Which card to upgrade depends on:
- Which card provides the highest marginal return per upgrade.
- Whether the upgrade removes Exhaust, increases damage/block values, or reduces energy cost.
- The specific fight approaching (boss vs. elite vs. normal).

Exact upgrade effects for each Ironclad card should be verified against the installed build before prioritizing. Card upgrade values are not sourced in this guide.
