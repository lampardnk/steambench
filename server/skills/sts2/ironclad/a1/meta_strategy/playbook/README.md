# Playbook — Editable Decision Template

> **Editable** — All content below is strategic inference or placeholder. Replace with patterns verified through live play. No thresholds, tier rankings, or matchup predictions should be treated as authoritative until observed.

## Turn 1 General Priority (Template)

A possible order of operations for turn 1 of combat. Not all steps are always correct:

1. Play Powers if drawn (common priority: scaling first, then defense).
2. Apply debuffs (Vulnerable/Weak) before Attacks.
3. Play Attacks with debuffs active.
4. Block if incoming damage is lethal or threatens critical HP loss.
5. Cycle (draw/return) to find key cards if energy remains.
6. End turn.

{strategic inference} Exact ordering depends on the specific fight — adapt based on enemy intents and your current hand.

## Boss Prep (Template)

Before a boss fight, verify from the installed game state:
- [ ] HP state — rest or continue based on current run conditions, not fixed thresholds
- [ ] Scaling plan (Strength engine, Exhaust engine, or block shell) is functional
- [ ] Potions equipped if inventory allows
- [ ] Path to boss includes a Rest Site (sourced: wiki.gg Map_Locations — guaranteed before boss)

## Elite Engagement (Template)

{strategic inference} Whether to fight an elite depends on:
- Current HP relative to the specific elite's damage output (check encounter guide or wiki)
- Whether your deck has the relevant tools for THAT elite's mechanics
- Rest site availability between you and the elite

No fixed HP thresholds are reliable — evaluate per-encounter using the installed build's monster data.

## Card Pick (Template)

Before adding any card, the following are useful questions — not hard rules:
1. Does this card solve a problem my deck currently has?
2. Is it stronger than my worst-performing card?
3. Does it dilute my deck's draw toward a key combo?
4. Am I taking it because it's generically "good" or because it specifically helps here?

{strategic inference} Card evaluation changes with each run's relics, encounter pool, and current build.

## Potion Usage (Template)

{strategic inference} General guidance:
- Use potions when they meaningfully increase your chance to survive a fight.
- At a reward with full potion slots, discard a less useful potion if the replacement is better. Use a potion only when the current screen permits it and its effect is beneficial.
- Boss fights reward using potions earlier rather than later.
