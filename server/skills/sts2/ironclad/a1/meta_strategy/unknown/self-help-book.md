# Self-Help Book

**Acts:** Any Act.

## Options

| Option | Exact outcome |
|---|---|
| **[Read the Back]** | Choose an Attack to enchant with **Sharp 2**; Sharp increases damage from that card by 2. |
| **[Read a Random Passage]** | Choose a Skill to enchant with **Nimble 2**; Nimble increases Block from that card by 2. |
| **[Read the Entire Book]** | Choose a Power to enchant with **Swift 2**; the first time you play that card, draw 2 cards. |
| **[Move On]** | Nothing happens. |

Each reading option is available only when a valid card can receive that
enchantment. **[Move On]** is available only when there are no valid cards.
No event-specific ascension variant is listed.

Compare the current enchantable cards with the exact effect; follow live options
if they differ.
